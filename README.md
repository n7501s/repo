# AI Agent & System Architecture

Добро пожаловать в наше ядро! Тук управляваме развитието на автономната ни екосистема.

## ✅ Current Features
- Успешно завършени тестове на автономния агент и създаден работещ dev бранч за тестване.
- Автоматично обновяване на документацията в `README.md` от самия бот в хода на разговора, без нужда от изрични команди.
- Интеграция с модела `gemini-3.5-flash-lite` с поддръжка на текст и прикачени файлове (изображения).

## 🚀 Ideas & Roadmap
- **Директни линкове към код:** Разработване на модул за четене на файлове и код в репозиторито чрез директни GitHub линкове (без спамене на код в чата).
- **Directory Tree Crawling:** Обхождане на цялата файлова структура и подпапки в репозиторито само чрез началния линк на хранилището.
- **Разширяване на файловите формати:** Тестване и добавяне на поддръжка за всички формати файлове, които Gemini моделът може да обработва.
- **Възстановяване на контекст от Issue-та:** Четене на стари Issue-та по линк при зацикляне на чата за безпроблемно прехвърляне на историята.
- **Deep Search & Web Crawling:** Способност за обхождане на уеб страници, блогове и YouTube видеа за анализ и обобщение.
- **Използване на онлайн инструменти:** Интеграция с външни уеб услуги за специфични задачи (напр. конвертиране на формати) вместо писане на собствен код.
- **Self-Healing & Multi-Agent Swarm:** Самолекуваща се система с четене на логове, автоматични тестове и координация между множество агенти/профили в мащабни задачи.
